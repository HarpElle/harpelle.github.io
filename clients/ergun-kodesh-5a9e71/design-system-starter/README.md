# Ergun Kodesh Design System starter

This is a practical handoff packet for collaborators using Claude Design or Claude Code. It is a small, editable code-based source package: upload/link the folder as design-system source material, then compare it with the canonical Claude Design project before publishing work.

## Included

- `tokens.css` — proposed semantic color, spacing, type, and radius tokens used by the public demonstrations.
- `tokens.json` — the same values in portable structured form.
- `USAGE.md` — workflow for using the source with Claude Design and keeping two congregation sites consistent.

## Important

The canonical visual source remains the Ergun Kodesh Claude Design project. This starter is designed to be a convenient collaborator handoff, not a replacement for the project or a claim that it exports private Claude Design internals.
