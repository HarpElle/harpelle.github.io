# Working with this starter

1. Open the canonical Ergun Kodesh Claude Design project first and request access if needed.
2. In Claude Design, attach or import this folder as source material for a new project; in Claude Code, use `/design-sync` with the folder/codebase when the connected account supports it.
3. Treat `tokens.css` and `tokens.json` as the shared baseline for the public demos. Update both files together after approved design-system changes.
4. Keep congregation-specific content, imagery, and ministry needs separate from the shared foundation.

For production, add approved logos, font licenses, final photography, and accessibility review before publishing.
