Retiring a page

  1. Swap the client’s index.html to the declined state the day they say no.
  2. On the promised rest date, delete pitch/ and demo/ from the repo and swap the page to the archived card.
  3. Keep a private copy of everything outside the repo (the repo history has it anyway, but keep a clean folder).
  4. Update the status and dates in studio-private/clients.json and this index so both stay honest.
  5. No follow-up emails. The archived page holds the door open by itself.

Conventions

HarpElle/studio-private   ← records: clients.json,
                            dossiers, logs, playbook
clients/<name-xxxxxx>/    ← on harpelle.com, unlisted
  index.html              ← landing (noindex, nofollow)
  pitch/                  ← pitch canvas
  demo/                   ← navigable demo

Pages are unlisted, not authenticated: no links from the public site, noindex, nofollow on every page, and the folder path is the only key. This index lives at its own unguessable path — don’t share it.
